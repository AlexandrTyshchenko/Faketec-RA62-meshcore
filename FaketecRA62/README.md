# Faketec RA62 — MeshCore для Faketec + HT-RA62 (SX1262)

Прошивки MeshCore для **Faketec (ProMicro nRF52840)** з радіомодулем **HT-RA62 (SX1262)**, сенсорами, RTC та GPS із захистом від спуфінгу.

Основа — гілка `dev` MeshCore (meshcore-dev/MeshCore, коміт `c4258a5b`) з усіма змінами FakeSolar, крім FakeSolar-специфічних (SX1268, канал батареї INA3221). Конфігурація збірки: [`variants/faketec_ra62/platformio.ini`](../variants/faketec_ra62/platformio.ini).

## Залізо

| Вузол | Модель | Підключення |
|---|---|---|
| MCU | ProMicro nRF52840 (Faketec) | — |
| Радіо | HT-RA62 (SX1262), TCXO 1.8 В, DIO2 як RF-switch | стандартна розводка Faketec |
| Сенсори (за наявності) | AHT20, BMP280/BME280, INA219, INA226, INA3221 | I²C SDA=8, SCL=7 |
| RTC (за наявності) | DS3231, RV3028, PCF8563, RX8130CE | I²C |
| GPS | NMEA, UART (швидкість визначається автоматично: 9600, 115200, 38400) | RX=3, TX=4, EN=5 |
| Дільник батареї | 1 МОм до «+», 1.5 МОм до «−» (множник 1.465) | ADC пін 17 |

> HT-RA62 розрахований на 868/915 МГц; на 433 МГц чутливість і потужність можуть бути нижчими.

## Прошивки

| Файл | Роль |
|---|---|
| `Faketec_RA62_repeater.uf2` / `.zip` | Repeater |
| `Faketec_RA62_sensor.uf2` / `.zip` | Sensor |
| `Faketec_RA62_companion_radio_ble.uf2` / `.zip` | Companion (BLE, PIN `123456`) |

Прошивка UF2: двічі натиснути reset → з'явиться USB-диск → скопіювати `.uf2`.
ZIP — для DFU, веб-flasher або OTA (`start ota`).

Радіопараметри за замовчуванням: **433.650 МГц, BW 62.5 кГц, SF 8, CR 8**. Змінюються через `set radio f,bw,sf,cr` або застосунок. Пароль адміністратора repeater/sensor за замовчуванням `password`, його треба змінити.

## Що змінено відносно MeshCore

- **Регістр 0x8B5** (`SX126X_REGISTER_PATCH`): біт для RX/AGC, повторно записується після кожного скидання AGC.
- **Скидання AGC**: чекає завершення калібрування; пропускається, поки йде прийом або є пакет на передачу.
- **TCXO у standby**: TCXO не вимикається між Rx/Tx.
- **Рівень шуму**: перші 50 мс після старту прийому не враховуються.
- **АЦП батареї**: множник 1.465 під дільник 1М/1.5М, час вибірки 40 мкс.
- **GPS** (код MeshCore `dev`): автовизначення швидкості UART, вмикання раз на 30 хв (`GPS_PERIOD_DEFAULT=1800`), захист від спуфінгу (`GPS_GUARD`, регіон — Україна: 44.0–52.5 пн. ш., 22.0–40.3 сх. д.).
- **CLI**: `telemetry` (усі сенсори текстом), `time force <epoch>` (виставити час, зокрема назад).

## Дільник батареї

```
set adc.multiplier <x>    0 = значення зі збірки (1.465), діапазон 0–10
get adc.multiplier
```

Працює на всіх ролях, включно з компаньйоном. Множник = 3600/4096 × (R_верх + R_низ) / R_низ. Наприклад, 680k/330k → 2.690.

## Команди GPS

Працюють у repeater і sensor; у companion — усі, крім `gps setloc`, `gps advert` і `get/set advert.loc`. Позначка «зберігається» означає, що значення переживає перезавантаження і перепрошивку.

### Стан і керування

| Команда | Що робить | Приклад відповіді |
|---|---|---|
| `gps` | стан GPS: `active` — зараз шукає/читає, `waiting` — спить до наступного вмикання; супутники і вік останнього fix; режим | `> on, waiting, 12 sats 21s ago, periodic (1800s)` |
| `gps on` / `gps off` | увімкнути / вимкнути GPS (зберігається) | `OK` |
| `gps period` | поточний інтервал у секундах | `> 1800` або `> 0 (continuous)` |
| `gps period <час>` | інтервал вмикання: `30m`, `1h`, `600s`, `1d`; `0` = GPS працює постійно. Заодно вмикає GPS (зберігається) | `OK` |
| `gps once` | позачергово знайти fix; `gps once -s` — ще й синхронізувати час | `OK - waking gps` |
| `gps sync` | синхронізувати годинник при наступному достовірному fix | `OK` |
| `gps setloc` | записати поточну позицію GPS у `lat`/`lon` ноди | `OK` |

### Діагностика

| Команда | Що показує |
|---|---|
| `gps fix` | останній fix: координати і кількість супутників |
| `gps fix_stats` | час до fix: останній / максимальний; скільки спроб поспіль вдалося (`ok`) і не вдалося (`miss`) |
| `gps diag` | живлення, байти UART, речення NMEA з правильною (`ok`) і хибною (`bad`) контрольною сумою, супутники. Якщо `bad` росте, а `ok` ні — модуль на іншій швидкості UART |

### Захист від спуфінгу

| Команда | Що робить |
|---|---|
| `gps guard` | стан захисту: перша частина — позиція, після `time` — час, напр. `> ok 12sat time ok +0s` |
| `gps guard on` / `off` | увімкнути / вимкнути захист; вимкнений приймає будь-який fix і час (зберігається) |
| `gps fence` / `gps fence <м>` | радіус геозони навколо `set lat`/`set lon` (за замовчуванням 1000 м); `0` = геозона вимкнена, лишаються межі регіону (зберігається) |
| `gps ref` | центр геозони (= `set lat` / `set lon`) |
| `gps guard accept` | при тривозі `ALERT` підтвердити, що правий GPS, і записати час GPS у годинник |

| Позиція | Значення |
|---|---|
| `ok 12sat` | fix достовірний, 12 супутників |
| `settle 2/5` | fix у межах, але ще не набралось 5 узгоджених fix поспіль |
| `no fix 0sat` | модуль не дає fix |
| `rej region` | fix поза регіоном зі збірки (Україна) — спуфінг |
| `rej fence 0.3km` | fix далі за геозону від позиції ноди |
| `rej jump` | «неможливий» стрибок від останньої достовірної позиції |
| `rej sats` / `rej hdop` | замало супутників або HDOP > 4.0 — слабкий сигнал |
| `off` | захист вимкнено |

| Час | Значення |
|---|---|
| `time ok +1s` | час GPS прийнято, різниця з годинником 1 с |
| `time -` | з GPS ще не приходив час |
| `time wait` | остання перевірка пройшла, свіжого fix зараз немає (GPS спить) — годинник у порядку |
| `time rej nofix` | достовірного fix немає (наприклад, під час спуфінгу) — час GPS не беремо |
| `time rej step 3600s` | GPS розходиться з годинником більше, ніж дозволено (понад 10 хв, далі — дрейф кварца) |
| `time rej range` | час GPS раніше дати збірки або пізніше за +10 років |
| `ALERT gps-clk +3600s 75m` | GPS 75 хв стабільно розходиться з годинником на +3600 с: `gps guard accept`, якщо правий GPS, або `time force`, якщо правий годинник. Тривога лише в CLI, у телеметрію не йде |

### Позиція в адвертах

| Команда | Що робить |
|---|---|
| `get advert.loc` | поточний режим |
| `set advert.loc none` | не показувати позицію в адвертах |
| `set advert.loc prefs` | показувати задану вручну позицію (`set lat` / `set lon`); за замовчуванням |
| `set advert.loc share` | показувати поточну позицію з GPS |

Стара форма `gps advert [none|prefs|share]` теж працює, але лише коли в збірці є GPS.

## Збірка

```bash
pio run -e Faketec_RA62_repeater -e Faketec_RA62_sensor -e Faketec_RA62_companion_radio_ble
```

Debug-збірка з логами запуску: `Faketec_RA62_repeater_debug`. Усі зміни одним патчем: `faketec_ra62.patch` (відносно meshcore-dev/MeshCore `c4258a5b`).

## Перевірено

Лише збірка. На залізі (HT-RA62) ще не перевірено; той самий код GPS, AGC і сенсорів перевірено на FakeSolar (SX1268).
